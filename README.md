## 📖 About

Task Scheduler is a modern task management web application designed to help users organize and track their tasks through a simple Kanban-style workflow.

Tasks can be organized into three stages:


To Do → In Progress → Done

The application provides a clean interface for creating, managing, searching, and tracking tasks.

✨ Features
📌 Task Management
Create new tasks
Move tasks between stages
Track task progress
Delete individual tasks
Delete all tasks
📋 Kanban Board

Tasks are organized into three clear workflow stages:

📝 To Do
🔄 In Progress
✅ Done
🔍 Search

Quickly search through existing tasks using the built-in search functionality.

📊 Task Statistics

The application provides an overview of:

Total tasks
Tasks in progress
Completed tasks
🌙 Dark Mode

Switch between light and dark themes for a more comfortable experience.

📱 Responsive Design

The interface adapts to different screen sizes and devices.

🎨 UI / UX

The design focuses on simplicity, usability, and visual clarity.

The Kanban board makes it easy to understand the current status of tasks at a glance.

Responsive Web Design
